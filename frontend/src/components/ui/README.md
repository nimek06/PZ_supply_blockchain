# Prymitywy UI

**Języki:** TypeScript/TSX, Tailwind CSS.

Plan: button, card, badge, dialog, table, alert, input - generowane przez
shadcn/ui lub proste komponenty zgodne z przyjętym stylem.
Dodawaj tylko potrzebne elementy, nie całą bibliotekę z góry.

Wspieraj klawiaturę, focus, etykiety formularzy i semantyczny HTML.
Nie używaj wyłącznie koloru do przekazywania statusu; dodaj tekst.
Brak HTTP, portfela i reguł produkcji w komponentach bazowych.
Testuj istotne zachowania i dostępność zamiast snapshotu całego HTML.
