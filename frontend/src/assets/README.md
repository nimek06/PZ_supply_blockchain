# Zasoby importowane

**Formaty:** SVG, PNG/WebP, ewentualnie fonty; importy w TypeScript/CSS.

Tu umieszczaj zasoby używane przez komponenty, żeby Vite przetworzył
nazwy i cache. Stałe publiczne URL należą do public/.
Pilnuj licencji i rozmiaru. Nie przechowuj generowanych QR partii,
raportów IPFS ani danych użytkowników.
