# Plany tygodniowe

Każdy tydzień ma osobny folder:

- `weekN-plan.md`: plan tygodnia i zadania zespołu.
- `weekN-summary.md`: podsumowanie wykonanej pracy.
- `plans/`: indywidualne plany osób (gdy istnieją).
- `notes/`: notatki techniczne, pomiary i raporty powstałe w danym tygodniu.

2026-11-11. Pełny system Anvil/Kubo; Amoy tylko jako dodatkowy skrypt dema.
Plany i notatki tygodni 1–2 są historyczne: ich zapisy o Pinacie, pełnej
integracji Amoy i terminie startu frontendu nie nadpisują bieżących planów.
Podsumowania zachowują faktycznie wykonane prace, nie są przepisywane pod nowy zakres.
